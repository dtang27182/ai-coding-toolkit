# Define and Confirm Requirements

Work in the initialized `<outputDirectory>/<feature>/<feature>.hld.md`, preserving `Design Guidelines`.

1. Follow the caller's requirements-definition instructions.
2. Ask the user every recorded clarification question. After each response, update both requirement sets as needed, remove answered questions, and add necessary follow-ups.
3. Present all high-level and detailed requirements for review. Repeat clarification and review until `Clarification Questions` is `None` and the user explicitly approves both requirement sets. Only then proceed to design generation.
